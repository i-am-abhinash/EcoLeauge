## 🌍 Overview

**EcoLeauge** is a gamified environmental education platform designed to promote awareness about sustainability and environmental protection.

The project focuses on making environmental education more engaging by combining educational content with interactive activities and game-like progression.

Instead of relying only on traditional learning methods, EcoLeauge explores how **gamification can encourage students to participate, learn, and develop greater awareness of environmental issues.**

---

## 🎯 Problem

Environmental education is important, but traditional learning approaches can struggle to keep students engaged.

Students may understand environmental concepts in theory without developing strong motivation to explore or apply them.

EcoLeauge approaches this problem through:

- Interactive learning
- Gamified progression
- Rewards and points
- Environmental challenges
- Real-world sustainability topics

---

## 💡 Solution

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/i-am-abhinash/EcoLeauge.git
```

### 2. Navigate into the project

```bash
cd EcoLeauge
```

### 3. Install dependencies

Install the dependencies defined by the project's client and server configuration.

```bash
cd client
npm install
```

If the server has its own Node.js package configuration:

```bash
cd ../server
npm install
```

### 4. Start the application

Run the appropriate development command defined in the client and server package configuration.
